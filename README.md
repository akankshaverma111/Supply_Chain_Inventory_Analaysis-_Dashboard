#📦 Supply Chain & Inventory Analysis Dashboard

## 📌 Project Overview
This Power BI dashboard provides an interactive analysis of supply chain and inventory performance. It helps monitor key business metrics such as revenue, profit, units sold, shipping time, delivery delay, inventory status, and top-selling products.

## 🎯 Objectives
- Analyze Total Revenue and Profit
- Track Total Units Sold
- Monitor Average Shipping Time
- Identify Delivery Delays
- Visualize Inventory Status
- Discover Top Selling Products
- Filter data by Supplier, Category, Warehouse Location, and Order Date

## 📊 Dashboard Features
- KPI Cards
- Bar Charts
- Donut Chart
- Interactive Slicers
- Clean and Professional Layout

## 🛠️ Tools Used
- Power BI Desktop
- Power Query
- DAX
- Excel Dataset
